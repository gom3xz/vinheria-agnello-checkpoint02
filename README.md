# Vinheria Agnello — Checkpoint 02

Sistema de avaliação de estoque e tendência de vinhos desenvolvido para o Checkpoint 02 de Web Development.

## Funcionalidades

- Cadastro de vários vinhos em sequência
- Validação das informações digitadas
- Verificação de estoque baixo para quantidades menores que 5
- Classificação dos vinhos como Jovem, Amadurecido ou Antigo
- Exibição dos dados por alert e console
- Contagem total de vinhos cadastrados
- Contagem de vinhos com estoque baixo
- Identificação do vinho com a safra mais antiga
- Utilização de funções e laços de repetição
- Armazenamento por variáveis individuais, sem arrays ou objetos
